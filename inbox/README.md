# 實作素材收件匣

把「技術筆記」或「Ubuntu 套件功能」的實作截圖和操作紀錄放在這裡，Claude 會整理成文章。
這個資料夾不會出現在網站上，上傳到 `main` 也不會觸發部署。

## 怎麼上傳（GitHub 網頁）

1. 打開 repo 的 `inbox/` 資料夾，按 **Add file → Create new file**。
2. 檔名輸入 `主題資料夾/說明.md`，例如 `2026-10-livepatch/說明.md`（輸入 `/` 會自動建立資料夾），寫好說明後按 **Commit changes**。
3. 進入剛建立的主題資料夾，按 **Add file → Upload files**，把截圖拖進去，再按 **Commit changes**。

## 說明.md 要寫什麼

不用寫得很完整，條列就好：

- 要寫成「技術筆記」還是「Ubuntu 套件功能」；單篇、新系列，或是哪個系列的第幾章
- 你看到的議題或想介紹的產品，有參考的官方文章或文件就附上網址
- 實作環境，例如 Ubuntu 24.04 LTS、LXD 6.10
- 每個步驟做了什麼、輸入了哪些指令、對應哪張截圖、遇到什麼問題

## 截圖命名

用兩位數字開頭排順序，例如 `01-install.png`、`02-status.png`。截圖前請遮住密碼、Token、IP 位址等敏感資訊。

## 上傳完之後

回到 Claude Code 對話說一聲，例如：「inbox/2026-10-livepatch 已上傳，寫成技術筆記單篇」。
Claude 會把截圖搬進文章資料夾、開 PR 給你預覽，你確認後才會合併上線；處理完的素材會從這裡移除。
